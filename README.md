# Modern Audit Website

A responsive, multi-page corporate web application built for an audit, assurance, and advisory firm, designed to showcase professional services, firm background, and client inquiry workflows.

## Features

- **Multi-Page Corporate Architecture:** Dedicated pages for Home (`index.html`), About Us (`about.html`), Audit & Advisory Services (`services.html`), and Client Inquiries (`contact.html`).
- **Responsive Design:** Clean, structured layout styled with custom CSS (`styles.css`) to adapt seamlessly across desktop, tablet, and mobile viewports.
- **Interactive UI Components:** Client-side interactivity, navigation controls, and form validation powered by vanilla JavaScript (`script.js`).
- **Client Consultation Portal:** Streamlined contact interface allowing prospective clients to request audits, assurance reviews, or financial consultations.

## Tech Stack

- **Markup:** HTML5 (`index.html`, `about.html`, `services.html`, `contact.html`)
- **Styling:** CSS3 (`styles.css`)
- **Interactivity:** Vanilla JavaScript (`script.js`)
